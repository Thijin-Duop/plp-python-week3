# Week 3 Assignment on Conditions and Loops

## Grade Reporter & Bug Hunt

This repository contains my Week 3 Python assignment on conditions and loops.

* **grade_reporter.py** — Uses a `for` loop and conditions to calculate grades, pass/fail counts, and the average score.
* **bug_hunt.py** — Finds and fixes three bugs in a `while` loop program that calculates the sum from 1 to 5.

The hardest bug to find was the `while` loop condition because the program could run without showing an error, but it stopped before adding 5. I knew something was wrong because the program was supposed to calculate the sum from 1 to 5, which should be 15, but the result was 10.
